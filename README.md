# PrimeCut Barbers

A premium single-page barber shop landing page built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Getting started

1. Install dependencies:
   npm install

2. Start the development server:
   npm run dev

3. Open the site in your browser:
   http://localhost:3000

## Useful scripts

- `npm run dev` — run the app locally
- `npm run build` — create a production build
- `npm run start` — serve the production build

## Windows PowerShell note

If the terminal blocks script execution, run:

`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`

before running npm commands in that session.
